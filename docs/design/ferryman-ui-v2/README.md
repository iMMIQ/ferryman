## 信息架构

主入口为新建翻译、翻译任务、模型与算力。桌面使用窄侧栏；手机使用底部导航。
新建翻译以文件、设置、提交的顺序呈现，不在首屏展开模型维护与高级参数。
桌面右侧提供最多三条最近任务；完整检索和分页放在任务页。

保持现有森林绿品牌与浅色主题：强调色 `#176B50`、画布 `#F4F6F5`、正文
`#17211D`，白色面板，8px 间距网格，8–12px 圆角，控件触达区域至少 44px。
实现时复用当前 Vue、Reka UI 和设计变量，不引入新的组件框架。

## 核心交互

1. 文件来源支持上传、文稿与网盘，明确选中列表、大小、移除操作与格式限制。
   选中文件后缩小上传区，给设置和操作按钮留出空间；长文件名可换行。
2. 常用设置包括目标语言、模型、双语/仅译文、保存位置；高级参数折叠展示摘要。
   表单草稿在切换任务页后保留。DOCX 的双语限制继续明确提示，不能仅在提交后报错。
3. 提交前显示文件数量、语言和输出方式。上传期间按钮展示进度并禁止重复提交；
   成功后进入任务页并突出新任务，失败时保留输入并就地解释原因。
4. 默认保存副本，显示实际结果路径。图中的“原文件不会被修改”仅适用于非覆盖模式；
   选择覆盖原文件时改为明确警示，并保留现有影响文件清单与二次确认。
5. 进行中任务同时显示阶段、百分比及段落数；完成任务突出下载；失败任务显示可理解的
   原因与恢复操作。部分段落失败应标为“完成，有未译段落”，不能使用无警告的完成状态。
6. 手机的固定提交区在底部导航之上，预留安全区和等高内容留白，不遮住设置或验证提示。
   图中的顶栏菜单不作为必要入口实现：已有底部导航，避免重复导航。

## 模型和连接状态

| 状态 | 页面行为 |
| --- | --- |
| 算力舱连接正常、模型未加载 | 显示“已连接 · 待机”；继续编辑，按现有按需启动机制处理提交 |
| 模型加载中 | 显示启动阶段和真实进度；无可靠估时则不编造剩余时间 |
| 模型未下载 | 在模型选择附近显示下载要求及现有下载操作，不伪装成就绪 |
| 算力舱离线 | 持续显示连接提示和重试入口；保留文件选择与表单草稿 |
| 加载失败 | 展示可读错误摘要、重试和可展开详情，避免弹窗反复打断 |

模型管理仍保留现有下载来源、下载进度、暂停下载、启动/卸载及删除确认功能。
任务页不添加后端尚未支持的“暂停翻译”。当前运行模型与表单选择模型应分别表达，
不能把选择了模型等同于模型正在运行。模型与算力入口复用可访问对话框，关闭后恢复原页面和键盘焦点。

## 实现验收

- 1440px 桌面突出表单与最近任务；中等宽度缩窄侧栏，任务摘要移到表单下方；
  390px 手机单列无横向滚动。不能用缩放整个桌面画面实现手机布局。
- 状态同时使用文字与图标；普通文字目标对比度至少 4.5:1，键盘焦点清晰。
  任务计数使用中性色，红色专用于错误，不照搬手机稿中的红色普通计数徽标。
- 文件移除、模型管理、取消等图标操作有可访问名称；任务进度有语义化属性，
  动态状态播报节制，不因轮询不断打断读屏。
- 覆盖确认、模型删除等对话框正确管理焦点；返回后恢复焦点位置。
- 覆盖空列表、长文件名、多文件、离线、下载、启动、部分失败、提交失败与手机键盘场景。
- 图片用于视觉参考；真实 DOM 控件、字体、键盘行为和业务限制以实现验收为准。
